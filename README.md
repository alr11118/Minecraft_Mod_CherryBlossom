# Pink Gold

<!-- INSERT MEDIA: Pink Gold banner image -->

<!-- Recommended: place your full Pink Gold banner here -->

A vanilla-inspired Minecraft mod that adds **Pink Gold** as a new material, giving Gold a pink upgrade.

Pink Gold is inspired by real-world pink/rose gold, combining the familiar look of gold with copper-inspired coloring. In Minecraft, **8 Gold Ingots + 1 Copper Ingot** can be crafted into Pink Gold, which can then be used to create armor, tools, a sword, and blocks.

## Features

Pink Gold adds a complete material set designed to fit naturally into vanilla Minecraft.

### Pink Gold

* Pink Gold Ingot
* Pink Gold Block
* Pink Gold Sword
* Full Pink Gold Armor Set
* Pink Gold Tools:

  * Pickaxe
  * Axe
  * Shovel
  * Hoe

Pink Gold's stats are designed to sit between **Gold and Diamond**, making it a stronger alternative to regular Gold while keeping the vanilla progression and feel of Minecraft.

## Installation

### Requirements

Before installing Pink Gold, make sure you have:

* Minecraft **Java Edition**
* Minecraft **26.1**
* **Fabric Loader**
* **Fabric API**, if required by the current release

Pink Gold is currently developed for Fabric and Minecraft 26.1.

### Step 1 — Install Fabric

If you do not already have Fabric installed, download the Fabric Installer and select **Minecraft 26.1**.

Follow the Fabric installation instructions for your operating system.

After installation, open the Minecraft Launcher and make sure a Fabric 26.1 installation/profile is available.

### Step 2 — Download Pink Gold

Download the latest compatible Pink Gold release from the **Modrinth page**.

> Make sure you download a version specifically marked for **Minecraft 26.1** and **Fabric**.

### Step 3 — Install Fabric API

Pink Gold may require Fabric API depending on the current release.

Download the appropriate Fabric API version for Minecraft 26.1 and Fabric.

Make sure the Fabric API version is compatible with your Minecraft version.

### Step 4 — Locate your `mods` folder

Place the downloaded `.jar` files into your Minecraft `mods` folder.

On macOS, the folder is normally located at:

`~/Library/Application Support/minecraft/mods`

On Windows:

`%APPDATA%\.minecraft\mods`

On Linux:

`~/.minecraft/mods`

If the `mods` folder does not exist, you can create it manually.

### Step 5 — Launch Minecraft

Open the Minecraft Launcher and select your **Fabric 26.1** installation.

Launch Minecraft.

If everything is installed correctly, Pink Gold should load alongside Fabric and appear in-game.

### Troubleshooting

If Minecraft does not launch:

1. Make sure you are running **Minecraft 26.1**.
2. Make sure you are using **Fabric**, not Forge or another mod loader.
3. Make sure your Fabric API version matches Minecraft 26.1, if required.
4. Make sure the Pink Gold `.jar` is inside the correct `mods` folder.
5. Make sure you are using the latest compatible Pink Gold release.
6. Check the Minecraft crash report or log for the specific error.

For additional information, see the official Fabric documentation.

## Development

Pink Gold was created as a personal challenge and as my first Minecraft mod.

I wanted to challenge myself by working with a much larger and more complex codebase than I was used to. Minecraft modding required me to understand how my code connected to existing Minecraft systems rather than working entirely within a project I controlled.

One of the biggest challenges was learning how to manage and debug a project with a large codebase and many interconnected components. Working through those problems helped me become more comfortable with debugging, navigating unfamiliar code, and understanding how different parts of a larger software project interact.

I also really enjoyed the process of turning an idea into something that could actually exist inside Minecraft. Pink Gold started simply because I thought it would be cool to have, but it became a project that pushed me to learn more about Java, Fabric, Minecraft's codebase, and resource systems.
